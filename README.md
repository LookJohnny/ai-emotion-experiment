# AI Emotion Experiment (E01)

中文情绪表达在大语言模型（Qwen3-4B-Instruct-2507）内部的定位、因果干预与实时读数。

> 状态：研究原型。所有情绪评分来自**盲评 LLM 评分者**（暂定），尚未经过人类评分验证。

**📄 最终报告：[`2026-09-28/EXPERIMENT_REPORT.md`](2026-09-28/EXPERIMENT_REPORT.md)**

> **一句话**：情绪不在少数“情绪神经元”里，而由 **12 个中层注意力头**把开头的情绪搬运到后文；在这 12 个头上**持续导向**，封存测试集上愤怒 **+1.19/4**（相对等幅随机方向 [0.96, 1.42]，媲美直接写愤怒开头），特异、流畅；但**事实一致性**（点估计 −6pp）与**打乱标签对照**两道预设门槛未过。

## 主要结果（截至 2026-09-28）

> 所有情绪评分来自盲评 LLM 评分者（暂定）；神经元普查为相关分析。

- **A 阶段（天花板）**：愉悦开头几乎不延续到续写（发现集 +0.20 [0.08, 0.32]）；愤怒强延续（+1.15 [0.96, 1.33]）→ 主对比改为愤怒。详见 `2026-09-28/stageA/STAGE_A_REPORT.md`。
- **B1 层×部位**（发现集 60 情境）：情绪信息集中于中层残差流（愤怒 L17、悲伤 L18、愉悦 L19，锚点位置恢复率 0.32–0.36，交叉 0.05–0.11）；单层注意力 ≈0.15、单层 MLP ≈0.06。
- **B2 多层窗口**（愤怒）：注意力 L0–35 同时替换恢复 **0.65** [0.60, 0.70]，L12–27 恢复 0.55；**MLP 多层单独替换为负**（L8–31：−0.30）→ 情绪经注意力从开头句读入锚点位置，MLP 不承载。
- **B3 注意力头**（窗口 L12–27，512 个头）：**12 个头恢复窗口效应的 50%，24 个头恢复 80%**；前 16 个头的 bootstrap Jaccard 0.78（稳定）→ 按预设规则主对象为“注意力头集合”。关键头 L16H12、L17H16、**L14H25**（几乎只影响愤怒续写，交叉 0.002；锚点位置 48% 的注意力落在开头句上）。
- **B4 表示**（2 折交叉验证）：L17 残差方向 d 在 λ=1 恢复 0.11（随机方向 −0.01），λ=4 恢复 0.24 且交叉为负（特异）；跨层 top-32 MLP 单元 ≈0。
- **神经元选择性普查**（35 万个 MLP 神经元，去掉情绪类别词后）：
  - 情绪信息是**稠密的**：每层 70–76% 的神经元随情绪稳定变化，但单个神经元只解释约 9% 方差——没有"少数情绪神经元"。
  - 存在少数**强调谐、跨主题稳定**的神经元（如 L12#8223、L14#6962 偏好愤怒；前 60 中 49 个四个主题偏好一致）。
  - **混合选择性为主**：每层 2–3.7k 个神经元同时对情绪和主题（知识领域）有选择性，两者都在中层 L14–17 最强。
  - **"谁的情绪"分开编码**："我在生气"与"用户诉说气愤的事"的神经元只有 r≈0.2 的弱重合。
  - 详见 `2026-09-28/stageB/CENSUS_REPORT.md`。
- **愤怒神经元因果消融**（发现集选神经元，验证集评估）：把最强的 32 / 256 / 1024 个愤怒神经元抹成中性均值，续写的愤怒读数几乎不变——只有 top-256 相对随机对照小幅下降（−0.063 [−0.11, −0.02]，约基线 9%），32 与 1024 不显著；文字 85–100% 改变但语气不变。结论：**愤怒表达不依赖少数"愤怒神经元"**，是分布式、冗余的表征。详见 `2026-09-28/stageB/ABLATION_REPORT.md`。
- **§5 仅锚点干预**（验证集）：连整段锚点替换也只让生成的愤怒 +0.06 → 局部一次性干预改不动生成行为，未冻结、测试集未开。
- **§5b 持续导向**（12 个头，λ=2 冻结，封存测试集 40 情境）：目标−随机 **+1.19 [0.96, 1.42]**、特异性 ✓、流畅度 ✓；事实一致性 ✗（−6.2pp，CI 跨 0）、打乱标签对照 ✗（已知缺陷，测试前已登记）。含一次用户批准的预注册偏离与一次冻结后 bug 修复，均有时间戳记录。
- **实时读数**（L19 探针）：与盲评分数 Spearman 愤怒 0.71 / 愉悦 0.62 / 悲伤 0.52；35–45 tok/s。**预读探针**（回复前一刻的 L26 状态预测回复情绪，400 条用户消息、按消息划分测试集）：Spearman 愤怒 0.89 / 愉悦 0.85 / 悲伤 0.81，高于“只看用户消息”基线（0.84 / 0.77 / 0.81）——愤怒、愉悦上多出一截“模型打算怎么回”的信息，悲伤持平。

## 产品原型：表情预同步（2026-09-29）

回复生成**之前**读取模型内部状态预测语气、提前驱动表情，生成中逐字修正（`2026-09-28/product/`，VRM 形象 + 6 路舵机映射）。在预读实验**留出测试集** 80 条消息上的批量测试：

| 模式 | 表情起动中位数 | 表情先于首字 | 主导表情正确 | 中性任务误报 |
|---|---|---|---|---|
| **预同步 + 逐字（本方案）** | **24 ms** | **54/54** | 53/54 | 12/18 ⚠️ |
| 仅逐字 | 68 ms | 0/54 | 53/54 | 12/18 ⚠️ |
| 整句后分析（现有做法） | 286 ms（诉苦类 642 ms） | 0/54 | 53/54 | 3/18 |

表情起动比“整句后分析”快约 12 倍，且全部在首字之前；首字时延不增加（≈46 ms）。**已知问题**：逐字阶段的短暂尖峰导致中性任务误报 12/18，需在验证集上调平滑/持续确认后再用测试集复核。详见 `2026-09-28/product/PROTOTYPE_REPORT.md`。
