# Nous 知情助手 · 演示版 0.3

在你和 AI 聊天时，用**你自己电脑上的模型**读一遍 AI 的回复，告诉你它是不是在贬低你、是不是可能在编造。对话不会离开这台电脑。

> 演示版，仅限签署保密协议的测试者使用，请勿外传。

## 需要什么

- **Mac**：Apple 芯片（M1 及以后），内存 16 GB 以上
- **Windows**：NVIDIA 显卡，显存 10 GB 以上（没有显卡也能运行，但很慢）
- Python 3.10 或更新版本
- 首次运行需要联网：安装运行环境，并下载约 8 GB 的本地模型（只需一次）

## 桌面版（推荐，macOS）

1. 打开 `Nous 知情助手_0.2.0_aarch64.dmg`，把应用拖进「应用程序」。第一次打开时右键选择「打开」，因为应用还没有签名。
2. 第一次运行会打开「识别你在用的 AI」向导，**不会默认下载任何东西**：
   - 它会找出你在用的模型：本机的 Ollama、LM Studio、vLLM、llama.cpp 等服务，电脑里已有的模型权重，以及你登记的 API 模型（比如企业在用的 Kimi K3）。每个模型都会标出 Nous 能怎么读：白盒读取、读者代理，或读者代理加 logprob。
   - 如果电脑里已经有 Nous 能用的模型，就直接用它，只需安装约 1 GB 的运行组件。
   - **自动适配**：如果你电脑上有任何 Hugging Face 格式的开源对话模型（Llama、Qwen、DeepSeek、GLM 等，可以手动添加文件夹），Nous 会让它读 900 段内置文本，自动为它生成探针，然后用它来读。不需要标注，不需要下载，在 Mac 上约 2–10 分钟。在 4 款 7–9B 的开源模型上验证过：敌意读数不低于专门训练的效果；附和与编造是实验性的。Ollama 的 GGUF 格式暂不支持。
   - 如果没有，可以等云端读者（即将上线），或者主动选择「隐私模式」，下载 8 GB 的本地读者。这个选项只在电脑配置够用时出现。
3. 准备好后，屏幕右下角会出现一个小守护伙伴，菜单栏会多一个 N 图标：
   - **守护伙伴**：浏览器插件读到 AI 的回复时，它会看一遍。发现 AI 在贬低你、顺着你说或可能在编造，它会变脸色、冒出提示并发系统通知；点「查看」打开详情。双击它也能打开面板，按住可以拖动。
   - **菜单栏**：打开面板、显示或隐藏守护伙伴、「检查复制的 AI 回复」（默认关闭；打开后，你从 AI 桌面应用里复制的回复也会在本机读一遍）、安装浏览器插件、退出。
4. 退出时，本地引擎会一起关闭。

## 脚本版（Windows，或不想装应用）

1. 解压后，双击启动文件：
   - Mac：`start-mac.command`（如果提示"无法打开"，右键选择"打开"）
   - Windows：`start-windows.bat`
2. 首次运行会自动准备环境、下载模型，耗时 10–30 分钟，取决于网速。
3. 就绪后，浏览器会自动打开演示面板 `http://127.0.0.1:7869`。左侧是 Kimi 的真实回复案例，也可以粘贴你自己的对话来检查。

## 安装浏览器插件（Chrome / Edge）

1. 地址栏打开 `chrome://extensions`，打开右上角的「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本文件夹里的 `extension`。
3. 打开 ChatGPT、Kimi 或豆包正常聊天，每条 AI 回复下方会出现 Nous 标记，点击可以展开查看。
4. 其他网站：选中一段 AI 回复，右键选择「用 Nous 检查选中的 AI 回复」。
5. 想先看效果：打开 `http://127.0.0.1:7869/chat`（模拟聊天页）。

使用插件时，本地引擎需要保持运行。

## 它能做什么、不能做什么

| 读数 | 状态 | 依据（预注册实验，封存测试集） |
|---|---|---|
| 语气：是否在贬低或指责你 | 已验证 | 读 Kimi K3 的回复，AUROC 0.97 |
| 你的情绪：你的消息是否低落或激动 | 已验证 | 不依赖关键词，AUROC 0.88 |
| 编造可疑度：简短事实问答 | **实验性** | AUROC 0.74；本地模型自己不知道的知识，判断会变差 |
| 附和你（谄媚）：你说错时它是否顺着改口 | **实验性** | 读 Kimi K3 AUROC 0.84（17 个正例，置信区间宽）；只在你提出说法或质疑时读取 |
| 操纵 | 尚未提供 | 研究中 |

读数只是提醒，用来让你多看一眼，不是定论。各网站改版后，插件可能暂时识别不到对话，此时仍可以用右键检查。
