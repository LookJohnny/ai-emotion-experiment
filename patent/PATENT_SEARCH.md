## 2. 逐项风险评估

### 2.1 权利要求 1(a)：锚点读数 + 闭式方差解释比预筛选

- **最接近的文献**：CN121835622A（平安）、CN121659903A（北航）。其次是 CN121171488A、CN121962742A。
- **已公开的部分**：
  - 用一个前向计算得到的统计量给每个注意力头打分，排序后取 Top-N，再干预这些头。CN121835622A 的"方差比例"分数和 CN121659903A 的"均值差/方差"散度分数，在概念上已经覆盖了"闭式、只需前向、按方差/可分性打分"。
  - 按头选择、用于属性控制的做法（ITI 及其专利化版本 CN121171488A、US20250292760A1）。
  - 内容相同、属性不同的成对输入（CN121962742A 的跨语言对、CN120726450A）。
- **没有找到的部分**：
  - ① 在属性片段之后接一个 **token 完全相同的锚点片段**，只在锚点 token 处读取头输出；
  - ② 按内容组做方差分解，并**从分母里扣除场景/内容方差**（SS_attr / (SS_tot − SS_scn)，即组内偏 η²）。
  - 检索中没有任何专利同时具备 ①②。
- **判断**：1(a) 单独看**有新颖性，但创造性风险中等偏高**。审查员很可能用 CN121835622A 或 CN121659903A 加 ITI 来组合驳回，理由是"把可分性分数换成 ANOVA 偏 η² 属于常规统计选择"。答辩的关键在锚点设计带来的技术效果，比如消除内容泄漏、属性信号不受内容混杂影响，需要用实验数据（偏 η² 与朴素差值、与探针准确率的对比）来支撑。
- **学术现有技术**：ITI（arXiv 2306.03341）被 US20250292760A1 在说明书中明确引用，CN121503558A 也引用了它；CN121171488A 的方法基本就是 ITI。检索中没看到 AtP*（2403.00745）或 GCM（2602.16080）被这些专利引用，但审查员可以直接引用学术文献。

### 2.2 权利要求 1(b)：等残差推力下逐头注入 + teacher forcing 对数概率差 + 显著性符号筛选

- **最接近的文献**：CN121598999A（腾讯，按扰动权重和任务损失选关键头），属于因果选头，但做法是梯度训练掩码。CN119442242B 是在概率分布层面操作，属于间接相关。
- **没有找到的部分**：逐头单独注入差向量、**统一残差流推力（按范数归一）**、teacher forcing 下比较"目标属性参考续写"和"参考属性续写"的对数概率差、保留**显著为正**的头。Google Patents 上 "teacher forcing"+"steering vector"、"attention head"+"log probability"+"steering" 都是 0 命中。
- **判断**：**专利文献中的风险低**。主要风险来自学术现有技术：activation patching、AtP*（2403.00745）、GCM（2602.16080）都按因果效应给组件打分；ITI 也用干预后的效果做评估。审查员可能认为"用因果干预效果筛选组件"已经公知。答辩重点放在：(i) 等推力归一化，让头之间可以公平比较；(ii) 符号筛选，排除那些"相关但方向相反"的头；(iii) 与 1(a) 两段式组合后的计算量/效果优势。

### 2.3 权利要求 1 整体（a + b 两阶段）

- 没有检索到同时包含"闭式方差预筛选 + 因果符号复筛"两阶段的专利。最接近的单篇文献（CN121835622A、CN121659903A）都只有一段式选头。
- **判断**：整体组合**新颖性较强**，创造性取决于两段式是否带来超出叠加的效果（例如预筛选把复筛成本从全部头降到 N 个、复筛剔除预筛选中的反向头）。**建议把 1(a)+1(b) 合写成独立权利要求**，不要单独以 1(a) 作为独立权利要求。

### 2.4 权利要求 2：在提示末尾和每个生成 token 上持续注入

- **已大量公开**：CN121351840A（逐 token 注入残差流）、US20250292760A1（自回归生成中逐步施加 ITI）、NVIDIA 同族（#8–#10）、CN118796999A（已授权）、CN120849708A，以及 ITI/ActAdd 学术文献。
- **判断**：**单独看风险高，几乎没有新颖性**，只能作为从属权利要求，依附于权利要求 1 的选头结果。

### 2.5 权利要求 3：从选中的头读出属性状态，驱动虚拟形象/机器人表情或告警

- **最接近的文献**：NVIDIA US20260087328A1 / US20260087052A1（从内部激活判断状态，再触发导向或拦截，属于"读出 → 告警/动作"）；CN121351840A（实时监测语义状态）。

## 5. 检索局限

1. **只用了 Google Patents**。WIPO PATENTSCOPE 的检索页是 JSF 会话表单，用脚本发 GET 请求会被重定向回检索首页，拿不到结果列表；Espacenet REST 接口返回 403；CNIPA 专利检索及分析系统（pss-system）返回 412，需要登录或浏览器验证。这三个库都**没能独立检索**。Google Patents 已收录 CN/US/EP/WO/KR/JP/DE 等主要局的数据，但 CN 新公开文献的收录可能有延迟，机器翻译也可能导致中文关键词漏检。
2. **18 个月公开延迟**：2025 年 4 月以后提交的申请大多还没公开。从 2025–2026 年 CN 申请的密度看（本表中有十几件），同类在审申请很可能还有更多。
3. 对每篇文献只读了独立权利要求和部分从属权利要求，没有通读说明书，也没有核查同族的全部法律状态（WO2025191986A1 等同族没有打开）。
4. "法律状态"取自 Google Patents 页面显示（Pending/Active/Granted/Withdrawn），不是官方登记簿。
5. 中文检索中，不加引号的词会被拆分，噪声很大；加引号的短语检索比较可靠，但同义词（例如"导向/引导/转向/操控 向量"）可能仍有遗漏。
6. **本报告是 AI 辅助初检，不构成法律意见。正式申请前，必须由专利代理人用 CNIPA、incoPat、Derwent 等专业数据库做查新/FTO 检索。**
