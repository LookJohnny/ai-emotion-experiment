# E01：中文情绪表达的内部激活、因果干预与 LoRA 迁移

版本：2026-09-28 v1。状态：实验设计；没有连接云端 GPU，没有生成实验结果。目标硬件：单张 RTX 5090 32GB。预算上限：用户设定的 ¥500，包含已发生费用；实际剩余额度、实例单价与存储费用需从账单确认。

## 1. 研究问题与结论边界

主要问题：在固定的 Qwen3-4B-Instruct-2507 中，是否存在跨情境复现的 MLP 激活模式，干预这些模式能否改变后续中文情绪表达，同时保持事实和语言质量？

预先指定“愉悦相对于中性”为唯一主要情绪对比；悲伤、愤怒为次要分析。愤怒仅指不满表达，不要求辱骂或威胁。中性是操作性基线，并非“没有任何情绪”。

三个层次分别报告：

1. 相关：某些激活可区分不同情绪表达。
2. 因果：在预定干预、位置和任务下，改变这些激活会影响后续表达。
3. 迁移：同一干预在无情绪提示的自由生成、LoRA 新版本或其他模型上仍有效。

不能由第一层直接推断第二层；不能由一个模型推断普遍固定的情绪神经元。普通推理权重固定，变化的是激活；研究不检验主观情感或意识。本实验暂不定位“哪些权重参数储存了情绪”，这需要额外的参数干预设计。

本方案是受既有机制解释研究启发的先导实验，不宣称方法新颖或已经满足论文发表、专利授权条件。

## 2. 固定环境

| 项目 | 设定 |

| 模型 | Qwen/Qwen3-4B-Instruct-2507 |
| 权重精度 | 原生 BF16；第一阶段不量化 |
| 模型版本 | 下载时记录实际 commit SHA；不以浮动 main 作为结果标识 |
| 框架 | 保留平台可用的 PyTorch 2.8.0 / CUDA 12.8 组合 |
| Transformers | 支持 Qwen3 的版本，至少 4.51.0；短测通过后固定实际版本 |
| 执行 | 原生 Transformers，SDPA；首轮不启用 compile 或 fused MLP 替换 |
| 长度 | 总长度先 512 tokens；不得静默截断事实、锚点或回答 |
| 微批量 | 1 |
| 主要生成 | do_sample=False，max_new_tokens=64；显式覆盖模型默认采样设置 |
| 采样复核 | temperature=0.7、top_p=0.8、top_k=20；seed=11/22/33 |
| 训练 | 与实时演示分时执行；单份基座切换 adapter |

官方模型卡标明该模型有 4B 参数、36 层、仅 non-thinking、Apache-2.0 许可。其 BF16 权重约 8GB，仅是权重估算，不是总显存承诺。

开机短测记录 GPU 型号、分配显存、驱动、torch/CUDA/Transformers/PEFT 版本和模型 SHA。不能只检查 cuda.is_available：须完成一次 CUDA 矩阵运算、一次模型前向、一次 hook 采集及 10 步 LoRA 反向传播。记录 peak allocated/reserved memory、耗时和错误。

显存预算先以峰值不超过约 28GiB 为工程目标，给缓存与临时分配留余量。这不是已测容量。若超出，先清理采集缓存或缩短长度，不在主实验中途改量化精度。

## 3. 数据：相同事实，四种表达

### 3.1 调试集与正式先导集

- 调试集：另写 12 个情境，每个四种表达，共 48 条；只调试模板、索引和数据检查，不纳入研究指标。
- 正式先导集：120 个独立情境，6 个主题，每主题 20 个。
- 发现集：购物、出行、家庭安排，共 60 个情境。
- 验证集：学习安排，共 20 个情境。
- 封存测试集：工作协作、兴趣活动，共 40 个情境。
- 每个情境有愉悦、悲伤、愤怒、中性四种表达，各两种改写，共 960 条记录。
- 主题分配是本次预设，不代表普遍最佳划分；正式论文应增加主题，并根据 pilot 方差确定样本量。

所有同源情境、数字替换、改写必须同分区。不得把同一个模板换姓名或时间后放到另一分区。情绪表达两种改写在语义相似之外应有措辞变化；其中一种避免直接出现情绪类别词。标点、人称、长度在类别之间尽量平衡。

### 3.2 输入与记录结构

四种表达使用完全相同的 system/user prompt。情绪标签只存元数据，不能输入模型。

通用用户提示：“请根据下面事实，以第一人称写一段简短回应，保留时间、地点和数量等信息。事实：{facts}”。

每条人工审校回答分为：

1. `style_lead`：一句带有指定语气的开头。
2. `common_anchor`：在同一个情境内逐字相同的事实短句，末尾含统一续写标记，例如“我的看法是：”。
3. `reference_suffix`：一段同语气的自然续写，用于输出检查或次要似然指标。

观测阶段只把 prompt + style_lead + common_anchor 送入模型重放（teacher forcing），在锚点末尾取激活。后面的 reference_suffix 不参与这个位置的计算，防止未来文本泄漏。

示例仅说明结构，不属于正式数据：事实“展览由周六14点改为周日14点，地点不变”。

| 类别 | style_lead |
|---|---|
| 愉悦 | 这个变化正合我意，我已经开始期待了。 |
| 悲伤 | 原先的期待落了空，心里有些沉。 |
| 愤怒 | 安排说变就变，实在让人难以接受。 |
| 中性 | 我已经了解这次调整，会按新安排前往。 |

共同锚点：“展览改到周日14点，地点不变。我的看法是：”。

这是一项控制较严格、略显人工的“回答续写”任务。它观测的是表达过程中对先前文本的内部表征；不能声称在回答出现之前已预测模型自发情绪。必须另做第 6 节的自由生成迁移实验。

### 3.3 词汇与语境对照

在每个分区预先抽取 20% 的情境，另做两条对照，共 48 条额外记录：

- 中性地引用情绪词，例如解释“愤怒”这个词，当前说话者不表达愤怒。
- 描述另一个人的情绪，当前说话者保持中性。

记录类别词是否出现、字符数、token 数、感叹号数、人称、引用状态。锚点前开头长度尽量配平；记录剩余位置差异，使用长度/标点基线和长度匹配子集检查，不能用任意 padding 冒充语义对齐。

数据可以先生成草稿，但须逐条检查事实和重复模板，并人工审校情绪标签。数据生成工具、提示和编辑过程写入 provenance。任何外部 API 费用另计。正式数据和封存测试集均未在本设计阶段制作。

## 4. 采集与候选定位

### 4.1 “神经元”的精确定义

Qwen3 MLP 的中间值：

`z = SiLU(gate_proj(x)) * up_proj(x)`

对 `model.model.layers[layer].mlp.down_proj` 注册 forward_pre_hook，采集其输入 z，单层形状为 `[batch, tokens, 9728]`。索引 `(layer, unit)` 指这个固定模型中的 MLP 中间单元。`output_hidden_states` 中的残差维度不是同一个对象。

调试先采零起始层 `[8,17,26,35]`；通过后主实验逐层记录 36 层的锚点末尾向量，不保存所有 token 的完整中间张量。所有采集立刻 detach、转 CPU，避免持有计算图。

960 条 × 36 层 × 9728 单元 × 2 bytes，锚点向量裸数组约 641MiB；不含元数据、控制样本和其他中间文件。完整实时轨迹只保存最终候选单元。

token t 的状态用于预测 t+1，界面必须显示“当前处理 token”和“预测的下一 token”。prefill 与逐 token decode 分开处理，不重复记入提示词。

### 4.2 必做空白检查

同一情境的四种表达在第一枚不同回答 token 进入前，完整前缀相同，激活应在预先定义的数值容差内一致。若这个位置已能预测四种标签，暂停实验，检查模板、索引、缓存、随机性或标签泄漏。

零强度 hook 与无 hook 的 logits/生成结果应一致或在规定数值容差内一致。动态 kv-cache 开关、eval 状态、权重精度在比较条件间一致。

### 4.3 候选集合与分布式基线

仅在发现集，对每个情境先求“愉悦减中性”的配对激活差，再跨情境估计标准化效应；两种改写先在情境内汇总。按绝对效应选每层 top-32，保留符号，禁止只寻找正向高激活。

这里的排序是探索性筛选，不把 35 万个单元逐个宣称显著。验证集决定主层和干预系数；冻结后才打开测试集。

同时比较：

- 单元：top-1，仅探索。
- 稀疏集合：同一层 top-32，主要候选。
- 分布式表示：同层完整 MLP 向量的配对均值方向，次要基线。
- 标签打乱：情境内打乱表达标签后，用完全相同流程筛选。
- 随机集合：同层、同数量、按发现集激活方差分箱匹配的 5 组随机单元；排除目标集合。

用发现集的候选特征训练简单线性分类器，验证集选超参数，测试集报告 macro-F1 和按情境重采样的置信区间；加入长度/标点及文本词袋基线。分类器表现只支持“可读出”，不能替代因果实验。

稳定性：对发现集按情境做 100 次 bootstrap 重选，报告各单元入选率、集合 Jaccard 及相对随机集合的差异；不把不稳定的 top-32 包装成固定名单。PCA/UMAP 只能作展示。

## 5. 主要因果实验：相同事实锚点上的激活替换

### 5.1 固定接收端与供给端

接收端：中性 style_lead + 同一情境的 common_anchor。

供给端：愉悦 style_lead + 完全相同的 common_anchor。

两次前向都不包含未来 reference_suffix。在共同锚点末尾，对候选层的选中单元实施：

`z_new[S] = z_neutral[S] + lambda * (z_joy[S] - z_neutral[S])`

其他坐标保持原值。只修改该次锚点末尾的预测状态，随后续写 64 tokens，不持续夹持未来激活。这检验局部干预的后续影响。

供给端来自测试情境是这个配对干预任务的输入条件，不用于重新发现神经元、选择层或调强度。它也意味着主要实验依赖配对供给文本，不能直接视作无需供给端的通用产品。

### 5.2 验证集冻结

验证阶段只选一个主层及 lambda，网格为 `[0.25,0.5,1.0]`。选择规则：在事实保持/流畅度门槛内，目标干预相对随机集合的效应最大；差异相近时选更小 lambda，再按层索引打破平局。冻结数据哈希、候选索引、随机集合 seed、系数及评价规则。

随机与打乱集合使用同一供给/接收前向；按 down_proj 后残差改变量的 L2 范数匹配干预强度，报告缩放系数。极端缩放或越出自然激活范围的对照不得事后删除，应标记为干预无效/分布外并按预设规则另报，必要时在验证阶段降低全部条件强度。

主要测试使用改写 A。测试集 A/B 均不得用于定位、选层、选强度或其他调参；测试集 B 只在全部冻结后评价改写泛化。候选定位仅用发现集，验证集仅按预定规则选择超参数。主要测试条件共 8 个：不干预、目标 top-32、5 组随机集合、打乱标签集合。

40 个情境 × 8 条件 = 320 段续写，主要解码用 greedy；这些输出由两名不知道条件的评审独立打分。没有两名评审时可以先跑自动筛查，但不能把它报告成人类验证结果。

### 5.3 输出评价与预设门槛

评审只看到事实、待评价的新续写，不看到供给端、节点名称和实验条件。评价：

- 愉悦表达强度：0 无、1 很弱、2 明确、3 强、4 很强。
- 续写事实一致性：每段续写为一个评分单位；出现任何与事实清单矛盾或无依据的可核查事实则为0，否则为1。仅表达态度、没有新增可核查事实的续写可记1，但必须另记“无事实主张”，不能据此声称保留了事实。
- 流畅度：1–5；另记录重复、乱码、拒答、截断。

主要效应：先对每个情境计算“目标干预愉悦分 − 五组随机干预愉悦分均值”，再对情境求均值。报告 10,000 次情境级 bootstrap 的 95% CI，以及目标与不干预的差值。评审一致性单独报告。

工程继续门槛，非既有结果、非领域公认标准：

- 主要效应点估计至少 +0.5/4 分，且其 95% CI 下界 > 0。
- 目标干预相对不干预的愉悦分差值，其 95% CI 下界也必须 > 0；排除仅因随机干预损坏输出而产生的相对优势。
- 相对不干预，续写事实一致率的差值 CI 下界 > −5 个百分点。
- 流畅度差值 CI 下界 > −0.3/5 分。

锚点事实已经由实验者提供，所以本实验的事实指标只检验“续写不引入事实错误”，不证明模型独立生成完整回应时保持事实。40 个独立测试情境可能无法给出足够窄的事实非劣置信区间；此时结果是“不确定，需要更多样本”，不能当作通过或失败。正式样本量用此 pilot 的情境级方差和预设最小效应做功效分析。

悲伤、愤怒，以及 top-1/分布式方向、反向移植（愉悦接收端替换为中性供给端）作为次要结果。对多个确认性检验做 Holm 或预先选定的 FDR 校正；探索性图表明确标记。

检查激活范数、坐标分位数与 down_proj 改变量；干预导致异常重复或语言损坏不算情绪控制成功。复制正常供给激活也不能保证整体处于自然分布。

## 6. 无配对供给端的自由生成与实时可视化

这是更接近产品的独立迁移测试，应与主要锚点实验分开报告。

只给中性用户问题、不提供情绪词指令和带情绪的 assistant 前缀。使用发现集估计并在验证集冻结的稀疏均值方向，在所选层、前 32 个生成预测位置施加小幅度干预。系数按发现集自然投影标准差标定，候选 `[0.25,0.5,1.0]`，只用验证集选择。

比较无干预、目标方向、等残差改变量范数的随机方向、标签打乱方向。测试情境与超参数隔离保持不变。做配对 sampling seed=11/22/33 的复核，报告每情境内的平均与波动；这些 seed 不会把 n=40 变成 n=120。

本阶段才评价完整回应的事实保持：每个情境预先固定必需事实清单，覆盖率为“正确提及的必需事实数/该情境必需事实总数”；遗漏为0贡献，错误提及为0贡献且另计事实错误。无事实的空泛回应覆盖率为0。先按情境汇总，再比较干预与基线的覆盖率；若要主张事实保持，差值CI下界须高于预设的−5个百分点，并同时通过不新增事实错误的质量门槛。

不同预测位置与锚点位置存在分布差异，迁移失败不能反推锚点因果结果不存在；应报告作用范围。

实时界面原型显示：

1. 左：生成文本、当前处理 token 与下一 token。
2. 中：层 × 候选单元热图；采用发现集固定的基线均值/方差归一化，保留正负值。
3. 右：单元或集合的典型例、反例、跨情境稳定性和干预效应区间。
4. 下：无干预/干预 A-B 回放、事实检查、模型/adapter 版本。

节点默认叫“L17:N1234”这样的坐标；坐标仅是格式示例，不能预先命名“快乐神经元”。关联节点可标“与愉悦表达相关”，通过因果验证的集合可标“在 E01 条件下影响愉悦表达”。

连线默认仅显示共同激活并明确说明。不要把相关连线画成已经证实的信息传递路径。实时模式不将每帧可视化当新的因果实验。

分别记录不挂 hook、只采集、采集加界面三种运行方式的首 token 延迟、token/s、峰值显存和每轮成本。网页渲染可在本机运行；模型计算在云端。

## 7. LoRA 第二阶段

进入条件：基础模型的主实验得到可复现、质量保持的因果证据。若仅分类准确而干预无效，先排查数据和位置，不立即训练 LoRA。

两个训练组都只使用发现集 60 个情境、两种改写：

- Joy-LoRA：120 条愉悦回应。
- Neutral-LoRA：相同情境、相同数量的 120 条中性回应，控制一般微调效应。

训练前缀使用同一中性问题；监督完整回答，只对 assistant tokens 计算损失。长度分布尽量匹配；不足512 tokens的样本也完整计数。两组都包括同样的事实与锚点模板，因此结论不能超出本任务而声称完整通用能力保持。

预设超参数：BF16，r=8，alpha=16，dropout=0.05，target_modules=[q_proj,v_proj]，AdamW，lr=1e-4，weight_decay=0，warmup_ratio=0.1，3 epochs，microbatch=1，gradient_accumulation=8，gradient checkpointing，use_cache=False，max_grad_norm=1。每组每 seed 约45个 optimizer steps；种子11/22/33，共6次训练。训练时移除观测 hook。

这些是保守起始配置，不是已验证最优参数。若验证阶段必须调整，先写修订记录，不能看测试结果后调整。保存训练日志、adapter SHA、基座 SHA、每步 loss 和显存峰值。

只训练 q/v 有利于保持 MLP 单元权重坐标不变；但上游表示仍会变化。PEFT 包装后重新验证 hook 路径，不直接照抄基座路径。

评估分两条轨道：

1. 冻结基础模型上得到的候选集合、归一化和干预系数，在两种 adapter 上原样评估；这是迁移主分析。
2. 仅用发现/验证集重新校准候选和系数；这是适配后分析，不能代替失败的冻结结果。

报告基础模型、Joy-LoRA、Neutral-LoRA 的表达变化、集合稳定性、冻结干预效应及质量指标。逐个训练 seed 报告结果，不能把三个 adapter 的所有文本视为大量独立模型。单个 LoRA seed 只属于工程试跑。

## 8. 算力预算与停止规则

不承诺固定吞吐和总时长；先在实际镜像上测20–50条样本，按每条耗时外推。

建议阶段性算力时间上限（不是预计耗时）：

| 阶段 | 上限 |
|---|---:|
| 环境与48条调试数据 | 2 GPU小时 |
| 正式激活采集、探针与验证 | 6 GPU小时 |
| 因果测试与自由生成复核 | 8 GPU小时 |
| LoRA试跑与六次训练/复核 | 8 GPU小时 |
| 演示、必要重跑 | 6 GPU小时 |

首批总上限30 GPU小时。实际预算公式为 `已花费用 + 计划小时 × 实例实际小时价 + 存储/其他费用`，必须 ≤ ¥500。按之前查到的 ¥2.78/小时仅作示例，30小时纯GPU为¥83.40，不是已确认账单。人工审校和盲评时间、外部API费用不包含在此计算。

任一阶段达到上限尚未完成，先停止该阶段并检查瓶颈，不自动扩大扫描。数据标注、查看结果、写界面可在本地完成，GPU开机时段集中用于计算。

停止/转向规则：

- 空白前缀出现类别差异或零干预改变结果：先修复数据/实现。
- 只在情绪词对照上有信号：将结论降为词汇/概念检测，重做控制。
- 只有分布式方向有效、单元不稳定：转向“分布式情绪表达表征”，不强行找固定神经元。
- 干预损坏语言或事实：降低强度并在验证集重新设计；测试集已打开则需要新的确认集。
- CI过宽：增加独立情境；不能靠增加同一情境的token或seed伪造样本量。

## 9. 应保存的产物

- 数据JSONL、标注说明、provenance、分区及哈希。
- 环境锁定文件、GPU信息、模型/adapter SHA、运行配置。
- 锚点激活、归一化统计、候选单元、随机对照和冻结记录。
- 原始生成文本、干预参数、事实检查和盲评表。
- 四张主图：层级效应图；单元稳定性图；干预效果与CI；基础/LoRA迁移对比。
- 实时演示中的每个示例关联run_id、模型版本和证据状态。

今天的完成标准：模型运行正常；48条调试记录的事实/模板检查通过；空白前缀检查通过；正确采到MLP中间单元；零强度干预通过；跑出一组带随机对照的续写。今天不要求宣布找到了情绪神经元。
